# Pioneree

Repository for the Pioneree demo application built on ASP.NET Zero.

## Development deploy

The repo includes a two-container dev setup and host reverse-proxy config:

- `docker-compose.dev.yml`
- `deploy/nginx/pioneree-dev.conf`
- `deploy/README.md`

Target URLs:

- `https://dev.pioneree.com`
- `https://api-dev.pioneree.com`
